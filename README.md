# emo-analyzer

I help my wife with Python project for university. Looks small, but I'm not a professional on Python at this moment, so it's probably there is a chance do it with less code :D

---

How to run with 5 steps:

1. install miniconda

  `https://www.anaconda.com/docs/getting-started/miniconda/install/overview`
   
2. create virtual env (use Python 3.11.15)

  `conda create --name emo-env python=3.11.15`

3. install matplotlib
   
  `conda install matplotlib`
  
4. install packages into virtual env
   
  `pip install DeepFace tf-keras`
  
5. for running I use VsCodium (opensorce port of VsCode without vendor packages)
   
  `https://vscodium.com/`


---

I run it in Win10 env, work well. I guess the same result in macOs and *nix.
